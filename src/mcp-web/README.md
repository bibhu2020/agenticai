# MCP Web Research Server

This is a Model Context Protocol (MCP) server for advanced web research and content extraction.

## Tools
- `search_web`: Google/DuckDuckGo search.
- `extract_content`: Extract text from URLs (uses Playwright).
- `research_topic`: Deep dive research on a topic.
- `wikipedia_search`: Wikipedia integration.
- `arxiv_search`: Academic paper search.

## Running Locally
```bash
python src/mcp-web/server.py
```
